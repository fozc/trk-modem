## Amaç

Ana uygulamaya alınmadan önce `libraries/json/json.c/.h` çekirdeğinin
doğruluğu, kaynak kullanımı ve tekrar çalıştırılabilir testleri
doğrulanmalıdır. Bu kayıt cihaz kabulü veya HTTP entegrasyonu olarak
yorumlanmamalıdır.

## Kapsam ve kararlar

- Kullanıcı bağımsız `json.c/.h`, ayrıntılı test ve sade API istemiştir.
- Son kullanıcı kararıyla ondalıklı API yalnız `float` destekler;
  `double` ve 64 bit integer dönüşümü eklenmemiştir.
- Token okuyucu, devam edebilen writer ve caller-owned buffer (çağıranın
  sağladığı tampon) kullanılmıştır. Heap, recursion ve platform bağımlılığı yoktur.
- DOM/key tablosu eklenmemiştir. Duplicate key politikası uygulamaya aittir;
  çekirdek bütün key'leri escape çözülmüş halde sırasıyla üretir.
- Yeni kaynaklar `Application/` dışındadır; CubeIDE ve mevcut endpoint'ler
  bu kütüphaneye bağlanmamıştır. NVRAM, protokol ve linker düzeni değişmemiştir.
- Karşılaştırmalarda değişken/fonksiyon soldadır. Yoda zorunluluğu
  `AGENTS.md`, `CLAUDE.md`, BARR-C §8.6 ve mimari rehberde değiştirilmiştir.
  Eski uygulama kaynakları topluca yeniden biçimlendirilmemiştir.

API, bellek ömrü ve hata sözleşmesi
[kütüphane rehberinde](../../libraries/json/README.md) tutulmalıdır.

## Tekrar çalıştırma

`test/` dizininde:

```text
ceedling json:check
ceedling json:coverage
ceedling json:arm
```

`json:arm` öncesinde `ARM_CC`, mevcut STM32 derleyicisinin tam yolu olarak
verilmelidir. Ayrı girişler `json:unit` ve `json:reference` şeklindedir.
Karşılaştırmalar ayrıca merkezi `run_all.rb` integration/critical koşularına
eklenmiştir. `test:all`, yeni Unity testlerini kendiliğinden içerir.

Testler şu kalıcı dosyalardadır:

| Yer | Sorumluluk |
|---|---|
| `test/libs/test_json_reader.c` | Syntax, token, Unicode, skip, hata konumu, giriş parçaları |
| `test/libs/test_json_writer.c` | Grammar, çıkış parçaları, sayım, kapasite, hata ve bağlam ayrımı |
| `test/libs/test_json_numbers.c` | Sayı türleri, sınırlar, hedefi koruma, float referans ve round-trip |
| `test/integration/json/json_bridge.c` | Gerçek public API'ye host ABI köprüsü; parser/codec mock'u yok |
| `test/integration/json/run_checks.py` | Bağımsız JSON/CRT karşılaştırmaları, Unicode taraması, exact midpoint, ölçüm |
| `test/integration/json/run_target_checks.py` | Hedef boyut/stack/undefined symbol kontrolleri |
| `test/plugins/json_checks/` | Ceedling görevleri ve coverage eşikleri |

Python karşılaştırmaları Unity'de JSON/float oracle'ını yeniden yazmamak
için host katmanında kalmıştır. **`ceedling json:check` ikisini birlikte
çalıştırır** ve alt komut hatasında başarısız olur. Python seed'i
`0x239375`, varsayılan rastgele örnek sayısı `100000`'dir. Gerekirse
`JSON_TEST_COUNT`, `CC` ve `PYTHON` ortam değişkenleri kullanılmalıdır.

Ceedling 1.0.1'in task plugin doğrulaması programmatic plugin kaydı da
beklediğinden boş `JsonChecks < Plugin` sınıfı vardır. Yeni hook veya
background iş eklenmemiştir.

## Hedef kaynak ölçümü

Araç: STM32 GCC **14.3.rel1**, Cortex-M33, Thumb, `fpv5-sp-d16`, hard-float;
`-ffunction-sections -fdata-sections -fstack-usage` ve proje sıkı uyarıları.

| Ölçüm | `-Os` | `-O2` |
|---|---:|---:|
| Tüm modül object `.text` + read-only veri | 6.886 B | 11.061 B |
| Global `.data` / `.bss` | 0 / 0 B | 0 / 0 B |
| En büyük tek compiler stack frame | 480 B | 512 B |
| `float_digits` frame | 352 B | 368 B |
| `json_reader_t` | 108 B | 108 B |
| `json_writer_t` | 164 B | 164 B |

Reader token tamponu ve writer çıkış tamponu bu bağlam boyutlarına dahil
değildir; çağıranın ihtiyacına göre verilmelidir. Writer sayı metni
tamponu 50 B'dir; fixed binary32 en fazla 50 B, dokuz anlamlı basamaklı
yazım 15 B, int32 yazımı 11 B üretir.

Otomatik kapılar: modül object boyutu ≤12 KiB, `.data/.bss` sıfır, tek
frame ≤512 B, her bağlam ≤192 B. Bunlar bu bağımsız modülün regresyon
bütçesidir; firmware'in toplam RAM/Flash veya task stack bütçesi değildir.

Undefined symbol listesi `fegetround`, `memchr`, `memcmp`, `memcpy`, `memmove`,
`memset`, `strlen` içerir. `fegetround` toolchain'de yalnız FPSCR okur;
heap/errno bağımlılığı olmadığı object üzerinde doğrulanmıştır.
`malloc`, formatter, float/double yazılım
yardımcısı veya locale çağrısı yoktur. Bağlı firmware'in gerçek artışı,
linker GC ve zaten kullanılan libc fonksiyonlarına göre değişir.

**Tek frame, en derin çağrı zincirinin toplam stack tüketimi değildir.**
Çağıran bağlamı/tamponları ve libc alt çağrıları bu sayılara eklenir.
Ana uygulamaya alınırken gerçek Contiki süreç stack payı incelenmelidir.
Bu aşamada linker veya firmware optimizasyon seçeneği değiştirilmemiştir.

## Host süre ölçümü

MinGW GCC 11.2 `-O2`, x86-64 Python 3.14/ctypes, Windows CRT oracle.
20.000 yineleme, 769 B ve 32 öğeli JSON belgesinde reader→writer aktarımı
tekrarlarda yaklaşık **51–91 MiB/s** ölçülmüştür. Float okuma yaklaşık
**0,97–2,02 µs**, yazma **0,79–1,57 µs** aralığındadır; ölçüm Python/ctypes
çağrı maliyetini içerir. Bu değişkenlikten hedef hız sonucu çıkarılmamalıdır.

Bu değerler garanti veya Cortex-M33 ölçümü değildir. Belge aktarımı
sayıları raw lexeme olarak taşır; float dönüşüm süreleri ayrıca ölçülür.
CPU/yük koşullarına göre değişen süre için otomatik hız eşiği konmamıştır.
Son tekrarın ayrıntısı yerel `test/integration/json/build/host_metrics.json`
ve `target_metrics.json` dosyalarına yazılır.

## Sınırlar ve sonraki kullanım

- Hedef derleme ve host testleri geçmiştir. Sonraki cihaz koşusunda
  84 Unity testi, DWT ve stack watermark ölçümü de geçmiştir; bütün
  host Unicode/reference vakaları cihazda tekrarlanmamıştır.
  Mevcut MinGW dağıtımında ASan/UBSan kitaplıkları
  bulunmadığından sanitizer sonucu yoktur; canary, coverage ve GCC analiz
  kanıtları sanitizer sonucu gibi sunulmamalıdır.
- Float tam IEEE binary32 aralığını kapsar; sayı başına mantissa sınırı
  128 rakamdır. Writer dokuz anlamlı basamak veya 0–9 sabit ondalık
  basamak verir; shortest seçeneği yoktur. Detaylar API rehberindedir.
- Okuyucu token tamponuna kopyalar; genel zero-copy reader bu ilk sürüme
  eklenmemiştir. Writer kaynak span'ını operasyon bitene kadar ödünç alır.
- HTTP Content-Length/snapshot, transport bekleme/iptal ve ayar transaction
  kuralları gerçek entegrasyonda sınanmalıdır. Bu kabul bunları doğrulamaz.
- Ana programa geçiş bu fazda yapılmamıştır; gerçek endpoint'lere alınırken
  ilgili mevcut web/config testleri ve hedef entegrasyon kabulü çalışmalıdır.

## Değişiklik geçmişi

Writer toplu kopyalama ve integer tek tarama sonrası ölçüm ve beş yeni
regresyon testi bu kayda işlenmiştir. Önce/sonra hız ve bağlı Flash farkları

dört ek testle güncel toplam 72, coverage ve kaynak ölçümleri yenilenmiştir.

olmuştur. Yukarıdaki coverage ve ARM değerleri bu son sürüme aittir.
Ek incelemede doğrudan float helper için 100.000 lexical mutation testi
kalıcı reference paketine eklenmiştir. 75 ayrı Unity testi, coverage ve
tam bağımsız paket tekrar geçmiştir; bu ekleme çekirdek kodunu değiştirmemiştir.
