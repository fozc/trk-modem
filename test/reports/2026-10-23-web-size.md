# Web yanıt kuyruğu boyut düzeltmesi

**Tarih:** 23.10.2026
**Sürüm:** 1.0

## Amaç

`index.html exceeds the HTTP response queue` derleme hatasının nedenini,
küçültme değişikliğini ve doğrulama kapsamını kaydeder.

## Kullanım yeri ve bulgu

`Application/gsm/gsm_http_server.c` içindeki TX kuyruğu 48 KiB'dir.
Ring yapısı bir bayt ayırır; header rezervi 512 bayttır. Bu nedenle
gömülü sayfanın sınırı **48.639 bayt**tır. Başlangıç gzip boyutu
**49.062 bayt** olduğundan mevcut static assert doğru şekilde durmuştur.

İngilizce sözlük 586, Türkçe sözlük 587 anahtar içeriyordu. İngilizcede
`fStopBits` eksikti. Mevcut `pack_i18n.cjs`, anahtarlar/sıraları uyuşmazsa
güvenli olarak sıkıştırmayı atlıyordu. Üretim sayfasında bu yol çalışıyordu;
önceki eşdeğerlik testi sıkıştırmanın gerçekten devreye girmesini şart
koşmadığından bu boyut kaybını yakalamıyordu.

## Değişiklikler

İngilizce Stop bits etiketi aynı anahtar konumuna eklendi. Mevcut sözlük
sıkıştırması tekrar çalıştı ve gzip boyutu 47.655 bayta indi.

Gömülü import/export doğrulama şemasından kullanılmayan `label` alanları
çıkarıldı. Kaynak JSON sözleşmesi ve doğrulama kuralları korundu.
Son boyut **47.057 bayt** oldu: başlangıca göre **2.005 bayt (%4,1)**
azalma, kuyruk sınırının altında **1.582 bayt** pay.

RAM kuyruğu, header rezervi, HTTP davranışı ve kullanıcı özellikleri
değiştirilmedi. Yeni sıkıştırıcı veya bağımlılık eklenmedi.

## Doğrulama

- Tam `make -C test/integration/web_navigation run` geçti. Kaynak/gömülü
  audit 42 kontrol, profile doğrulaması 40 kontrol verdi.
- Dil testi üretim anahtarlarının/sıralarının eşleşmesini ve sözlük
  sıkıştırmasının gerçekten çalışmasını artık zorunlu tutar.
- Minifier paketindeki yeni test index/fw_update/loading gömülü byte
  uzunluklarını header makrolarıyla karşılaştırır; gerçek GSM kuyruk ve
  rezerv sabitlerinden hesaplanan kapasiteyi aşmadıklarını denetler.
- ARM Release derlemesi ve imzalı EFW self-check geçti. Statik boyut
  kontrolü hedef toolchain ile doğrulandı. App CRC: `676A2BD0`.

Web sürümü 1.4.16 olarak korundu. Bu çalışma cihaza yükleme veya fiziksel
HTTP testi içermez. Kalan 1.582 bayt sınırsız büyüme payı değildir; yeni
ekran değişikliklerinde aynı boyut testi çalıştırılmalıdır.
